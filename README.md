# Shankar Agency

A React storefront and business website for Shankar Agency, covering hardware product sales and interior / wooden-work service offerings.

## Overview

This application is designed for a business that sells hardware products and provides home interior design and wooden work services. It includes:

- product browsing by category
- pricing display for hardware items
- add-to-cart and quantity adjustments
- checkout form for order placement
- interior design and wooden work service overview
- business contact and lead-generation section

## Project structure

- `src/App.jsx` — application layout and interactive behavior
- `src/App.css` — storefront styling and responsive layout
- `src/index.css` — global styles and resets

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Business requirements covered

1. Customer can browse hardware products and inspect prices.
2. Customer can add products to cart and update quantity.
3. Customer can place an order using a checkout form.
4. Business promotes home interior design and wooden work services.
5. Website uses a clean, modern design suitable for a local hardware and interior business.
